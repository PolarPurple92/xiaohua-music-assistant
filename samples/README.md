# 测试样本

`sample-score.pdf` 是随包附带的一张公版扫描谱页，用来让新用户不用自己找书就能试功能。

- 来源：https://commons.wikimedia.org/wiki/File:Bach_Matth%C3%A4uspassion_O_Haupt_voll_Blut_und_Wunden.jpg
- 许可：Public domain
- 作者：J. S. Bach
- 说明：Johann Sebastian Bach: O Haupt voll Blut und Wunden, vierstimmiger Chorsatz aus der Matthäuspassion

用法：打开软件 → 打开 PDF → 选这个文件 → 双击某一行谱试听。

如果你想用自己的书，删掉这个文件夹也没关系。
